# BockwurstWilly Labs

Landing page for all of BockwurstWilly's game projects: https://bockwurstwilly.github.io/

Plain HTML/CSS with a little JavaScript, no build step.

- **Add or change a project:** edit `projects.js` (one block per project, with screenshots in `img/`).
- **Downloads:** each Download button reads the latest GitHub release when the page loads. If the API can't be reached, the button links to the project's releases page.
- **Fonts:** Inter and Newsreader, served from this repo (SIL Open Font License, `fonts/OFL.txt`).
